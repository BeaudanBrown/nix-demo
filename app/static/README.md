# Nix logo

`nix-snowflake.svg` is the unmodified white Nix snowflake from:
https://github.com/NixOS/nixos-artwork/blob/master/logo/nix-snowflake-white.svg

Originally designed by Simon Frankau and revised by Tim Cuthbertson.
Licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/),
as documented in the [upstream logo README](https://github.com/NixOS/nixos-artwork/blob/master/logo/README.md).

The asset is bundled locally so the presentation does not depend on an external
image service. The white variant is intended for dark backgrounds.
